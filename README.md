# Hundo

**Where you are in your games, read straight from your saves.**

Hundo is a desktop app for Linux, macOS and Windows. It finds your games and
their saves, reads each one with a module written for that game, and shows
your progress and what is left for 100 %.

## Download

Get the [latest release](https://github.com/hundo-app/releases/releases/latest):

| System | File |
|---|---|
| Linux | `.AppImage` (updates itself), `.deb`, `.rpm` |
| macOS | `.dmg`, Apple Silicon (`aarch64`) or Intel (`x64`) |
| Windows | `.msi` |

The app checks for updates and installs them for you (Windows, macOS,
AppImage). Game modules update on their own, without a new version of the app.

## Supported games

Hollow Knight · Hollow Knight: Silksong · Hades · Schedule I · Clair Obscur:
Expedition 33. Each is a module in [hundo-app/modules](https://github.com/hundo-app/modules),
where anyone can add one.

## Privacy

Hundo reads your saves on your computer and keeps what it finds there. It asks
the Internet only for what you allow in **Settings → Internet**: game modules,
updates, achievement images, and the reports, roadmap and release notes on
GitHub. A report or a shared save leaves your computer only when you send it
yourself, from your browser.
